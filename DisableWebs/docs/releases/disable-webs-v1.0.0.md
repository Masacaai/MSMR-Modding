## Disable Webs 1.0.0

Press **F7** and Spider-Man can no longer swing, zip, point-launch or shoot webs. Press F7 again and everything comes back. For Marvel's Spider-Man Remastered.

> Back up your saves before you try any mod.

### What it blocks

- Swinging, zip to point, web snap, zip-jump, point launch, zip to a wall or ceiling.
- The web shooter and every gadget shot; web strike, yanks, throws and web bomb.
- **Wall-run corner tether** (hold DODGE at the edge of a wall).
- **Wall-run pull-up** (JUMP while wall-running). This also removes the ordinary jump off a wall while the lock is on.

Melee, dodge, wall-run, wall-crawl, the gadget wheel and the swing-kick (hold PUNCH in the air) still work.

### Requirements

- Marvel's Spider-Man Remastered, **`Spider-Man.exe` version exactly 4.0630.0.0**. On any other build the mod touches nothing.
- Overstrike 1.8.1 with **Enable .script support** and **Add '-scripts' to commandline.txt** on.

### Known Issues

- The lock starts off every launch; press F7 to turn it on.
- Scripted story moments that push Spider-Man into a web move directly may still use webs.
- With the lock on there is no web-catch when falling.
