# common

Source shared by the mods, compiled into each mod's DLL (the mods are built separately; there is no shared library at runtime). One copy of each file, never forked:
if two mods need something, it lives here. Layout rules: [docs/MAINTAINING_DOCS.md](../docs/MAINTAINING_DOCS.md).

## Engine layer (this folder)

| File | What |
|---|---|
| `log.*` | `LOG(...)` to a file next to the DLL's data, truncated each launch |
| `memory.*` | SEH-guarded reads and writes of game memory |
| `scan.*` | Signature scanning of `Spider-Man.exe` and RVA helpers |
| `gamethread.*` | Run a function on the game's main thread (hooked per-frame tick) |
| `watchpoint.*` | Hardware write watchpoints for the dev tools |

`gamethread.cpp` includes `natives.h`, which the mod supplies (from `game/`, or its own `src/natives.h`); it must provide `natives::GameThreadTick`.

## `game/`: game access used by several mods (Endless Arena, Echoes of Time, Disable Webs)

`natives.*` (the list of resolved game functions, each found by signature and checked against an expected RVA), `entity.*` (entity handles, health, bosses, hero position),
`spawn.*` (actor spawning and deleting; `preload_deps.inc` is generated by `tools/assets/deps.py`), `psinput.*` (PlayStation controller input). Facts behind them:
[docs/internals/](../docs/internals/README.md). Manhattan Skies keeps its own small `src/natives.h` instead; a mod never puts both on its include path.

## `modmenu/`: the Settings-tab library

One tab per mod in the game's Settings screen; see [modmenu/README.md](modmenu/README.md).

## `build/`: toolchain and packaging

`setup.cmd` (Visual Studio toolchain, MinHook via the root `vcpkg.json`), `finish.cmd` + `pack.ps1` (pack `<mod>\build\<File>.dll` into an Overstrike `.script` using the mod's `mod.json`,
copy it to Overstrike's Mods Library). Each mod's `build.cmd` calls them.
